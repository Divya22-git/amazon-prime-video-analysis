# amazon-prime-video-analysis
Amazon Prime Video Content Analysis Interactive Dashboard using Power BI

## Project Overview
An interactive Power BI dashboard developed to analyse Amazon Prime Video's content catalogue.

## Objectives
- Analyse total titles and content ratings.
- Explore genre distribution.
- Compare movies and TV shows.
- Understand country-wise content distribution.
- Analyse release-year trends.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV


## Key Insights
1. Movies account for approximately 80.82% of the catalogue.
2. TV shows account for approximately 19.18%.
3. Drama is the most represented genre in the displayed analysis.
4. The 13+ rating category has the highest count.
5. Content distribution increases in more recent release years.
